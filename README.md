# White Lotus — Halloween Reel

Вертикальный HTML-ролик **9:16, 25,6 секунды**. Сайт статический: **без Vite, npm-зависимостей, сборки и собственных GitHub Actions**.

## Просмотр

- **GitHub Pages:** `https://koryakinyurij.github.io/White-Lotus/` после публикации ветки `main`, папки `/docs`.
- **Локально:** откройте `docs/index.html` в браузере или запустите `python3 -m http.server 8000 --directory docs` и откройте `http://localhost:8000`.
- Для корректной типографики требуется интернет: пока подключаются шрифты Playfair Display и Manrope с Google Fonts. Ассеты и звук лежат локально.

После слияния PR: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder: `/docs` → Save**. Никакой файл `.github/workflows/` для сайта не нужен. Внутренние процессы публикации GitHub Pages управляются самим GitHub.

## Устройство

```text
docs/
  index.html             # Разметка пяти сцен и UI плеера
  styles/reel.css        # Стили и типографика
  scripts/assets.js      # Пути к ресурсам
  scripts/core.js        # Общие функции WAAPI и элементы сцены
  scripts/atmosphere.js  # Общий фон и атмосфера
  scripts/scenes/        # intro, lotus, program, date, finale
  scripts/effects.js     # Зерно, адаптивный размер текста
  scripts/player.js      # Шкала времени, пауза, звук, клавиатура
  scripts/morph.js       # Анимация превращения текста в кольцо
  assets/images/         # WebP изображения
  assets/audio/          # Фоновое аудио MP3
```

**Для агентов:** редактируйте только соответствующие части, не вставляйте Base64 обратно в HTML/JS, не меняйте имена ресурсов без обновления `scripts/assets.js`. Скрипты подключены как обычные `defer` в исходном порядке, потому что используют общий лексический контекст; не переставляйте их без проверки зависимостей. URL относительные, поэтому работают на GitHub Pages с префиксом `/White-Lotus/` и локально. Готовым результатом считается содержимое `docs/`, а не один монолитный HTML.

## Проверка перед PR

1. Запустите `python3 tools/verify_site.py` (без сторонних зависимостей) и `node --check` для каждого изменённого JS-файла, если установлен Node.js.
2. Откройте `docs/index.html` на мобильном и десктопном размерах; сравните 0, 2, 5, 9, 13, 18, 24, 25 сек., проверьте отсутствие ошибок консоли, анимацию, шрифты и границы кадра 9:16.
3. Проверьте паузу, перемотку, звук и режим safe-area. Если нужна автономная **одиночная** HTML-копия, это отдельная задача по упаковке, не входящая в Pages-разработку.

Исходный монолит v11.0.11 доступен в Git-истории (`cc50b4d`) для сравнений и восстановления; в рабочем дереве дублировать его не нужно.
